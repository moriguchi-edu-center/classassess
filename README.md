# 学級力アンケート 集計・レーダーチャート

Microsoft Forms の Excel を読み込み、学級平均のレーダーチャート表示・比較・書き込みができるツールです。

**使い方のまとめ（推奨）:** [`使い方ガイド.md`](使い方ガイド.md)

入口:

- [`index.html`](index.html) … ホーム（集計・グラフ / 分析・書き込みを選ぶ）  
- [`集計グラフ.html`](集計グラフ.html) … Excel読込・グラフ表示・画像書き出し（児童生徒も利用可）  
- [`分析書き込み.html`](分析書き込み.html) … グラフ画像への書き込み・分析  

標準の流れ: 共同編集/Forms → **集計・グラフ**で表示・画像化 → 共有 → **分析・書き込み**で話し合い。

Excel の元データは次のどちらかです（**Sheet1 の表形式はどちらも Forms 出力と同じ**）。

- **Forms 出力**の xlsx  
- **共同編集ブック**（個人シート `01`〜`45` に入力 → 関数で `Sheet1` に Forms 形式で集約。ツールは Sheet1 のみ読む）  

テンプレート: [`sample/共同編集テンプレート_数式集約版_教室用.xlsx`](sample/共同編集テンプレート_数式集約版_教室用.xlsx)

書き込み後の画像出力は、学級で見せ合って確認するためです。

## すぐ試す

1. ネット接続した状態で [`index.html`](index.html) を開く  
2. 「サンプルデータで試す」を押す  

または [`sample`](sample/) の Excel を第1〜3回に登録してください。

## 技術メモ

- 単一 HTML（CDN: SheetJS / Chart.js）
- サーバー不要・データはブラウザ内のみ
- 第1〜4回の重ね比較、書き込み、PNG書き出し対応

設問一覧・計算式・手動マッピングの詳細は [`使い方ガイド.md`](使い方ガイド.md) を参照してください。
